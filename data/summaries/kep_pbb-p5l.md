# Pengawasan PBB P5L (Perkebunan, Perhutanan, Pertambangan, dan Lainnya)

## Tabel Jangka Waktu Siklus Penatausahaan PBB P5L (KRUSIAL)
| Tahap | Jangka Waktu |
|---|---|
| Auto Creation SPOP — Periode I (Kebun, Migas, Pabum) | **1 Februari** |
| Auto Creation SPOP — Periode II (Hutan, Minerba, Lainnya) | **31 Maret** |
| Pelaporan SPOP oleh WP | **30 hari** |
| Penundaan Pelaporan SPOP | **7 hari** |
| Surat Teguran (bila WP tidak menanggapi Coretax) | **7 hari** |
| Klarifikasi (bila belum sesuai Penelitian Material) | **7 hari** |
| Penilaian Kantor | **5 hari** |
| Penilaian Lapangan | **15 hari** |

## Alur Proses (Probis Pengawasan → Penilaian → Pemeriksaan)
1. WP melaporkan SPOP (30 hari) atau mengajukan penundaan pelaporan (7 hari) → masuk **Coretax**.
2. **Coretax "Ya"** → **Penelitian Material**:
   - **Sesuai** → lanjut ke **Penilaian** (Kantor 5 hari / Lapangan 15 hari) → **Penetapan NJOP** → **SPPT**.
   - **Belum Sesuai** → **Klarifikasi** (7 hari) → jika **Menanggapi** → **Pembetulan SPOP** → Penilaian; jika **Tidak Ditanggapi** → **Anris Pemeriksaan**.
3. **Coretax "Tidak"** → **Surat Teguran** (7 hari) → jika **Menanggapi** kembali ke Coretax; jika **Tidak Ditanggapi** → **Anris Pemeriksaan** → **Pemeriksaan PBB** → **SKP PBB**.
4. **Pengawasan Pembayaran PBB** berjalan paralel terhadap hasil Penilaian/SPPT.

## Legend Probis (warna pada diagram asli)
- Hijau putus-putus = Probis **Pengawasan**
- Kuning putus-putus = Probis **Penilaian**
- Merah putus-putus = Probis **Pemeriksaan**

## Catatan
- Siklus ini menghubungkan tiga probis sekaligus: Pengawasan (SPOP/Teguran/Klarifikasi), Penilaian (NJOP), dan Pemeriksaan PBB (jika WP tidak kooperatif) — soal ujian sering menguji urutan & jangka waktu pada tiap simpul.
- Dasar NJOP PBB digunakan sbg dasar penghitungan PBB terutang dalam: SPPT (via SPOP/pengawasan), SKP PBB (pemeriksaan), keputusan keberatan PBB, keputusan pengurangan ketetapan PBB, penghitungan kerugian negara pada bukper, dan penyidikan.
