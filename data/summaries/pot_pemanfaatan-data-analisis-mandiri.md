# Pemanfaatan Data dan Analisis Mandiri (SE-05/PJ/2022)

## Sumber Data (2 Kategori Besar)
| Kategori | Rincian |
|---|---|
| **Data Eksternal / Pihak Ketiga** | Dalam Negeri: Data ILAP ber-PMK (**Pasal 35A ayat 1**) dan Data ILAP non-PMK (**Pasal 35A ayat 2**) — dari Instansi/Lembaga/Asosiasi/Pihak Lain. Luar Negeri: Data Eksternal Luar Negeri via **Competent Authority** |
| **Data Internal** | Data Produksi Unit Kerja DJP; Data SPT WP, Data SPT Lawan Transaksi, Data Elektronik Pendukung SPT — dari Wajib Pajak |

## Dua Tahap Pengelolaan Data
1. **Pembangunan Data** — Pencarian Data Eksternal + Produksi Data + Pengolahan Data SPT.
2. **Pemanfaatan Data** — dipertukarkan antara DJP ↔ Pihak Luar DJP.

## Teknik Analisis Mandiri (SE-05/PJ/2022)
- **Analisis SPT**
- **Analisis Laporan Keuangan** — contoh: **Penyusutan** (manfaatkan Apportal; sering ditemukan penyusutan tidak sesuai golongan harta); **Jembreng PPN** (penyandingan SPT PPN satu halaman — sering ditemukan kompensasi tidak nyambung/setoran tanpa dasar); **Ekualisasi** (logika dasar analisis kepatuhan material).
- **Analisis Transfer Pricing**
- **Analisis Proses Bisnis WP**

## Catatan — Fokus WP Strategis
Analisis mandiri idealnya mencakup **semua aspek WP Strategis**; makin besar skala WP makin kompleks aspeknya. AR harus memastikan WP penentu penerimaan di tiap seksi sudah divisit dan dipastikan keberadaannya.
