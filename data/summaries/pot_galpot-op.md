# Penggalian Potensi Wajib Pajak Orang Pribadi (Galpot OP)

## Kompleksitas vs Kesederhanaan Galpot OP
| WP OP | Karakteristik |
|---|---|
| **Karyawan** | Norma Penghitungan Penghasilan Neto biasanya tidak relevan; data cenderung dari pemberi kerja |
| **Non-Karyawan (Profesi, Pengusaha)** | Norma Penghitungan Penghasilan Neto **atau** Pembukuan/Pencatatan; sumber data: LHPt/LHA/KKA, Data Internal, Data Eksternal, Analisis Mandiri, Pencarian Data Baru (**KPD**) |

**Cons (tantangan Galpot OP):** perilaku sangat beragam; data internal & eksternal terbatas; analisis mandiri harus diperkuat; karakteristik defensif & tertutup; transaksi cash; comskill (communication skill) harus mumpuni.
**Pros:** analisis relatif sederhana; cakupan kreativitas luas; data lapangan relatif mudah; komunikasi langsung ke penanggung pajak; cakupan sampai tanggungan; resilience jadi modal utama.

## Teknik/Metode Penggalian Potensi (Observasi Lapangan)
Harta kekayaan (uang tunai, persediaan, tabungan, piutang, deposito, aktiva lancar lain); lokasi usaha (visit pusat & cabang); jumlah pegawai (estimasi biaya & omzet); mekanisme penjualan (kredit/cash, penjualan kembali, member); jenis usaha di lokasi (emas perhiasan/batangan, simpan pinjam, gesek tunai); durasi & jam operasional; wawancara end customer; riset medsos.

## Teknik Pencarian Data
Wawancara, elisitasi, pengamatan, berita & medsos, data internal.

## 8 Pendekatan Menghitung Omzet (hafalkan urutan)
1. Transaksi tunai dan nontunai
2. Sumber dan penggunaan dana
3. Satuan dan/atau volume
4. Penghitungan biaya hidup
5. Pertambahan kekayaan bersih
6. Berdasarkan SPT atau hasil pemeriksaan tahun pajak sebelumnya
7. Proyeksi nilai ekonomi
8. Penghitungan rasio

## Pendekatan Satuan dan/atau Volume — Formula (KRUSIAL)
```
Peredaran Usaha = Volume Usaha x Harga Jual
```
Jika volume hanya teridentifikasi untuk periode tertentu:
```
Proyeksi Volume Usaha = (Volume pada periode yang diidentifikasi / Periode yang teridentifikasi) x Setahun
```
Jika variabel berupa input/proses:
```
Vol. pada periode yang diidentifikasi = Vol. input pada periode tertentu x Persentase untuk menghasilkan output
```
Contoh satuan: kuantitas barang terjual/diproduksi, pemakaian bahan baku, jumlah kunjungan pasien, tingkat okupansi kamar.

## Pendekatan Penghitungan Rasio
Digunakan bila tersedia data pembanding (DJP/WP/pihak lain) dan kegiatan usaha WP dapat dibandingkan dengan rasio pembanding. Menguji/menghitung kembali: peredaran usaha, HPP, laba bruto, laba bersih, atau penghasilan bruto — dengan mengalikan basis data dengan persentase/rasio pembanding.

## Metode Penghitungan Biaya Hidup
Berdasar data biaya hidup WP + tanggungan, **tidak termasuk** pengeluaran menambah kekayaan. Jika WP tidak berutang → penghasilan minimal = biaya hidup (titik impas/**break even point**).
**12 kelompok pengeluaran biaya hidup:** konsumsi rumah tangga, transportasi, pendidikan, kesehatan, rekreasi, gaya hidup, sumbangan, olahraga, pemeliharaan harta, pengeluaran terkait perolehan penghasilan, pajak & retribusi, pengeluaran lainnya.

## Metode Penambahan Kekayaan Bersih
```
Penghasilan WP OP = Pertambahan Kekayaan Bersih + Biaya Hidup
```
Kekayaan Bersih = Harta − Kewajiban/Utang. Pertambahan Kekayaan Bersih = selisih kekayaan bersih awal vs akhir tahun.
