# Tahapan Proses Bisnis KPD & Tindak Lanjut

## Alur Tahapan Probis KPD (Urutan)
1. **Perencanaan & Koordinasi** → Surat Tugas (ST) → pelaksanaan KPDL (Tusi Wilayah/Tusi Lapangan/Non Tusi/Pihak Eksternal via PKS).
2. **Rekam pada Aplikasi Coretax**.
3. **Validasi Material** (oleh **Atasan Langsung**): kelengkapan field (NIK/NPWP valid, KPP tujuan benar, alamat jelas/lengkap, uraian data informatif); **relevansi** terhadap klasifikasi **ICALEP** (Income, Cost, Asset, Liability, Equity, Profile); **akurasi** nilai data.
4. **Validasi Formal** (oleh **Kasi PKD**): kelengkapan & validitas data; NIK via sarana tersedia (Appportal); standardisasi penulisan nama/alamat sesuai basis data DJP; data **belum ada** di basis data DJP; Masa/Tahun Pajak **belum daluarsa**.
5. **Pengolahan Data** (enriching, cleansing, dll) → **Penurunan Data** ke Direktorat DIP: jalur **Intensifikasi** (SIDJP Nine / Data Penguji — untuk WP ber-NPWP) atau **Ekstensifikasi** (Modul Ekstensifikasi Approweb / **DSE** — untuk WP belum ber-NPWP).
6. **Distribusi**: Kasi PKD → **Kasi Pengawasan II, III, IV, V, VI**.
7. **Penugasan** ke **AR** → **Penerbitan SP2DK** (hari berikutnya) → disampaikan **Langsung** atau **Pos/Kurir**.
8. **Respon Wajib Pajak** — 4 kemungkinan: (1) WP mendaftarkan diri; (2) WP tidak memberi tanggapan; (3) WP menolak mendaftar/menyatakan tidak dapat didaftarkan karena kondisi tertentu; (4) WP tidak ditemui/WP Kempos.
9. Output: **LHP2DK** → **Usulan**: (a) pemberian secara jabatan (**NPWP** atau **NITKU**); (b) kegiatan P2DK **tidak ditindaklanjuti** jika WP: tidak ditemukan / meninggal tanpa warisan belum terbagi / jadi SPLN / tidak memenuhi syarat subjektif-objektif / tidak ada indikasi kewajiban / telah memenuhi kewajiban.
10. Jalur lanjutan LHP2DK lain: **Pengawasan** (penyampaian/pembetulan SPT), **pengusulan Pemeriksaan/Pemeriksaan Bukper**, atau **tidak ada tindak lanjut**.

## Continuous Supervision — Fasilitas Action Selection (KRUSIAL — "KPD bukan sekadar kumpul data")
> "KPD tidak hanya untuk mengumpulkan data, namun juga dapat melakukan **tindak lanjut** atas update data profil WP atau action lain yang ditemukan selama KPD **secara jabatan**."

| Kondisi WP Ditemukan | Tindak Lanjut Jabatan |
|---|---|
| Data profil WP tidak update | **Perubahan Data WP secara Jabatan** |
| Status WP tidak update | **Perubahan Status WP secara Jabatan** |
| WP seharusnya PKP (omzet > Rp4,8 M) | **Pengukuhan PKP secara Jabatan** |
| WP memiliki objek PBB P5L | **Pendaftaran PBB secara Jabatan** |
| WP seharusnya Terdaftar/NIK aktif | **Aktivasi NIK/Pendaftaran NPWP secara Jabatan** |
| WP tidak seharusnya dapat fasilitas | **Usulan Pencabutan/Perubahan Fasilitas WP** |
| Data ditemukan, subjek tidak ditemukan | Permintaan Bantuan Pengamatan/Intelijen |
| Data ditemukan, nilai tidak diketahui | Permintaan Bantuan Penilaian |

**Contoh kasus (dari materi):** AR melakukan KPD berbasis wilayah, menemukan Toko Semar Jaya (supplier besar untuk toko lain). Hasil wawancara & observasi: penjualan harian >Rp20 juta. AR selain input data objek (pendapatan), **melakukan pengukuhan PKP secara jabatan** karena omzet setahun telah melebihi **Rp4,8 Miliar**.

**Manfaat Continuous Supervision**: mempercepat proses update/action jabatan; data diinput sesuai kondisi sebenarnya; mencapture seluruh informasi (tidak hanya ICALE).
