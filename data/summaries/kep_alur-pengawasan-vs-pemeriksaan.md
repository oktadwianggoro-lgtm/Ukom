# Persandingan Alur Pengawasan vs Pemeriksaan

**Dasar hukum:** PMK-111/2025 (Pengawasan) vs PMK-15/2025 (Pemeriksaan).

## Persandingan Dokumen (Step 1 Pengawasan → Step 2 Pemeriksaan)
| Pengawasan (PMK-111/2025) | Pemeriksaan (PMK-15/2025) |
|---|---|
| Surat Perintah Pengawasan | Surat Perintah Pemeriksaan (SP2) |
| SP2DK | S. Pemb. Pemeriksaan |
| Tanggapan WP | Tanggapan SPHP |
| BAP2DK | SPHP |
| LHP2DK / LHP2DKE | Panggilan → Pembahasan Temuan Sementara → BA Temuan Sementara → Undangan PAHP → Risalah PAHP → BA PAHP → Ikhtisar → KKP → LHP |
| DPP / DPE | — |
| SP2DKE & SPHPP | — |
| Undangan Pembahasan Akhir | (setara) Undangan pembahasan akhir |
| LHPt / LHPtE | — |

## Konsep Kunci
- Pengawasan adalah **Step 1**: menggali indikasi ketidakpatuhan via P2DK/Imbauan/Teguran; bila potensi belum terpenuhi dapat berlanjut ke **Step 2 (Pemeriksaan)**.
- Baik Pengawasan maupun Pemeriksaan sama-sama memiliki pola: pemberitahuan awal → tanggapan WP → pembahasan temuan → dokumen hasil akhir → ketetapan/tindak lanjut.
- Proses Bisnis Pengawasan mencakup baik **WP Terdaftar** (SP2DK, Imbauan, Teguran) maupun **WP Belum Terdaftar** (SP2DK → SPHPP, lihat kompetensi Ekstensifikasi) serta **Pengawasan Wilayah** (Kegiatan Pengumpulan Data — pengamatan, wawancara, geotagging, pengambilan gambar).

## Catatan
- Istilah dokumen pada jalur pemeriksaan (SPHP, LHP, SP2) **tidak boleh tertukar** dengan istilah pengawasan (SPHPP, LHP2DK, SP2DK) — meski mirip, keduanya berasal dari dua PMK berbeda dengan kewenangan dan jangka waktu yang berbeda.
